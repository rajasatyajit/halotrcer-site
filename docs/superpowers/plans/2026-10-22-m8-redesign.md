# M8 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the product's own (simulated, stamped) output the visual centre of the three sites,
route each buyer from the home page, and keep every existing gate green.

**Architecture:** Astro static pages and CSS only; no new islands. New pure functions in
`src/lib/` and `scripts/lib/` carry the logic and get unit tests. New dist checks join
`npm run check:dist`. One commit per task; each task is one step of proposal §9.

**Tech Stack:** Astro 7.4.1, TypeScript, hand-written CSS tokens, Vitest, Playwright 1.64.1 +
axe, resvg for OG images.

> **Superseded (2026-10-23):** Tasks 4–9 are replaced by `docs/superpowers/plans/2026-10-23-m8-case-file.md`. Tasks 1–3 stand.

**Spec:** `docs/redesign/proposal.md` (approved 2026-10-22; its "Owner decisions" table wins over
the rest of it). Project rules: `CLAUDE.md`.

## Global Constraints

- Lighthouse 100 × 4 (mobile) on key pages; LCP < 1.2 s, CLS 0, INP < 100 ms.
- JS ≤ 20 KB gz per page; page weight ≤ 250 KB; no new islands; no module shared between islands.
- Strict CSP: no inline scripts except `application/ld+json`, no `style=`, no third-party
  anything; system fonts only.
- Every product fact, number or quote renders through `<Claim>` or from a sourced file
  (`data-claim`, `data-sample`, `data-owner-source`, `data-source-doc`). Owner-sourced claims
  use `source: { owner: true, decided: 2026-10-22, note }`.
- `LAUNCHED=false`: no install commands, versions, GitHub links or star buttons. Run
  `npm run build:prelaunch && npm run check:prelaunch` in every task that adds content.
- WCAG 2.2 AA in both themes, keyboard, reduced motion, works without JS; colour never the only
  signal; 320 px wide without horizontal scroll.
- Every published URL keeps working; new pages are recorded with `npm run urls:record`.
- Never bare `npx`: use `npm run …` or `npx --no-install …`.
- Price text comes from `priceLabel()` (Task 6) or `formatPrice()` only. Prices in
  `content/pricing.md` are starting prices, so they read "From $X".
- The four home tiles are self-select prompts: never `<blockquote>`, `<q>`, `<cite>`, quotation
  marks or an attribution.
- Copy fixed by the spec (verbatim): "Simulated demo run"; "Example values (not real prices)";
  "Estimate from your inputs: not a measurement"; "Talk to us about referrals"; continuity
  claim `www.continuity` = "One maintainer today. Tokvera and Sievant are Apache-2.0, each a
  single binary you keep and run with no account. Halotrcer is Apache-2.0 too; it installs and
  runs those two binaries, which keep working without it."
- Local e2e/axe: `SERVE_PORT_BASE=4521` (ports 4321–4323 belong to another session's server;
  never stop it). Lighthouse and the full Playwright run only after the owner says go.
- **Stops:** after Task 3 and after Task 6, run `npm run shots -- after`, send the owner the
  changed pages' screenshots and wait.

## Review Focus

1. **A cropped piece of a sample loses its label.** Any `<table>` or `<section>` inside a
   `[data-sample]` region, and every report card, must contain `[data-stamp]` → `check:stamps`
   (Task 3), and the cards (Task 5) live inside `[data-sample]` so the check covers them.
2. **New content leaks pre-launch material.** The synced SECURITY.md (GitHub reporting route),
   the published sample JSON and `/agencies` must pass `check:prelaunch` → Tasks 3, 7, 8 each
   run it, and Task 7 adds a FORBIDDEN rule for "private vulnerability reporting".
3. **320 px phones.** The header (wordmark, Book a call, theme, Menu) and the stacked sample
   tables must not scroll sideways → `tests/e2e/layout.spec.ts` (Task 4) checks
   `scrollWidth <= innerWidth` on every key page at 320 px.
4. **JavaScript disabled.** The phone menu is `<details>`, so it must open without JS; the
   calculator's example label needs JS and must not leave a false "estimate" card →
   `header.spec.ts` (Task 4) with `javaScriptEnabled: false`; `calculator.spec.ts` (Task 7).
5. **Local tests hit the wrong build.** `reuseExistingServer` would test the other checkout's
   server on 4321 → Task 1 makes ports configurable and asserts the served build is this one.
