# M8 "The AI Case File" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the three sites as the detective's cork board of `docs/redesign/DESIGN.md`,
using our own components, with every gate still green.

**Architecture:** Astro static pages and hand-written CSS. The only new runtime asset is three
self-hosted WOFF2 fonts. Board content is computed at build time by pure functions in
`src/lib/clues.ts` from `content/samples/*.json`, so no number on a card is typed. The page uses
the existing `copy.ts` island and adds no new one. New checks join `check:dist`. One commit per
task.

**Tech Stack:** Astro 7.4.1, TypeScript, CSS tokens, Vitest, Playwright 1.64.1 + axe, resvg,
fonttools 4.66.1 (`pyftsubset`, local, already installed).

**Spec:** `docs/redesign/DESIGN.md` (owner-approved 2026-10-23) and the visual reference
`docs/redesign/reference/case-file.html`. The owner's message of 2026-10-23 and the
"Conflicts" section below (once approved) take precedence over DESIGN.md. Project rules are in
`CLAUDE.md`.

**Supersedes:** Tasks 4–9 of `docs/superpowers/plans/2026-10-22-m8-redesign.md`. That plan's
Tasks 1–3 are done (`c57980e`, `903a243`, `39a6bf8`), and this plan builds on them. The
proposal's wording and tiles are dropped. Task numbers continue from 4.

## Global Constraints

- Lighthouse 100 × 4 (mobile) on key pages; LCP < 1.2 s, CLS 0, INP < 100 ms.
- JS ≤ 20 KB gz and page weight ≤ 250 KB per page, fonts included. CSS ≤ 20 KB gz. No new
  islands: copying uses the existing `copy.ts` island (`data-copy="<id>"`).
- Strict CSP is unchanged (`font-src 'self'` already). No `style=`, no inline scripts except
  `application/ld+json`, no request to a third-party host.
- Fonts: exactly `permanent-marker`, `special-elite` and `karla` (variable, wght 400–800),
  as Latin-subset WOFF2 in `src/assets/fonts/`. Only Permanent Marker is preloaded. Every face
  uses `font-display: swap`, with a metric-matched local fallback face.
- Typography roles (DESIGN §3): Marker for headings, card titles, kind labels and prices,
  never body text. Special Elite for card body, case tags, stamps and table cells. Karla for
  everything else. Scale: display 96/68/40/24, body 19/17/15, small 13.
- No digit appears in board copy literals (`src/data/boards.ts`). Every number on a card comes
  from `sample()`, `<Claim>` or `content/pricing.md`.
- Every `[data-clue]` contains `[data-stamp]` reading "Simulated demo run" (CLAUDE.md
  verbatim), and sits inside `[data-sample="<id>"]`.
- Verbatim labels: Tokvera "Provisional scoring.", Halotrcer "Provisional.". The continuity
  claim `www.continuity` is the owner's text as it appears in the mockup.
- Price text comes from `priceLabel()` only. `content/pricing.md` keeps `from:`, so prices
  read "From $X" until the owner says they are fixed.
- `LAUNCHED=false`: no install commands, versions, GitHub links or star buttons. Every task that
  adds content runs `npm run build:prelaunch && npm run check:prelaunch`.
- WCAG 2.2 AA in both themes, keyboard, no JS, reduced motion, 320 px with no sideways scroll.
  The board looks the same in both themes; only paper sections switch.
- Permanent URLs: no page moves. New pages (none planned) would go through `npm run urls:record`.
- Never bare `npx`: use `npm run …` or `npx --no-install …`. Local servers use
  `SERVE_PORT_BASE=4521`. Run Lighthouse and the full Playwright suite only after the owner says
  go.
- **Stops:** (a) after Task 7 and (b) after Task 8. At each, run `npm run shots -- after`, send
  the screenshots and wait.

## Review Focus

1. **A cropped clue card loses its label.** `check:stamps` must fail on any `[data-clue]`
   without its own stamp, anywhere in dist → Task 6.
2. **A number typed into copy instead of read from a sample.** `boards.test.ts` fails on any
   digit in `src/data/boards.ts`, and `clues.test.ts` pins every rendered value against the
   JSON → Task 6.
3. **The font swap moves the layout, or slows LCP.** `fonts.spec.ts` delays the font responses
   and asserts the summed layout shift is 0 on `www/` → Task 4. If the owner agrees, one
   Lighthouse run on `www/` at stop (a).
4. **Phones.** Rotated cards and the board frame must not scroll sideways at 320 px, and the
   board must become one column at ≤ 47.5 rem with the yarn hidden → `layout.spec.ts` and
   `board.spec.ts` (Tasks 5 and 7).
5. **Dark theme and no JS.** Red labels on dark paper and the focus ring on paper, cork and wood
   → `contrast.test.ts` (Task 4). The case-file text is visible and selectable with JS off →
   `board.spec.ts` (Task 7).
